# 可选附录：把本技能产物手工挂到 LibTV / Seedance

> 本技能**不包含**付费生成、不调用 LibTV API / MCP、不消耗积分。  
> 以下仅供工作室同学在网页上手工操作。

## 建议挂载

| 本技能产物 | LibTV 用途 |
|-----------|-----------|
| `depth.mp4`（或 `depth_segXX.mp4`） | 视频参考 / 动作参考（mixed 模式） |
| 人物正脸静帧（你们自己准备，不在本仓库） | 图像参考（脸） |
| `ref_audio.m4a` | 音频参考（可选） |
| `prompt_zh.txt` 填好后的正文 | 提示词 |

## 注意

1. Seedance 2.0 常见单段约 4–15 秒；超过请用 `extract_depth.py --split-max 15` 的分段。
2. 提示词必须从 **t=0** 覆盖到片尾；用 `validate_prompt.py` 检查。
3. 积分以网页「生成」按钮显示为准；本技能无法代扣、也无法预知精确积分。
4. DEMO 水印深度片不要用于正式出片。
